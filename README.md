# Avatar Tower Defense


A **free** browser tower-defense game where your towers are Muse avatars in different gear. Runs on desktop and iPhone — no install, no account, just open and play.


**Play it now:** https://muse.ai/s/avatar-tower-defense-xvxu6exnexuxxbtxj


## How it plays


- **Waves & levels** — Each level throws 20 waves at you across a fresh map, then you move on. Towers reset every level and you get starting credits to rebuild.
- **Chapters** — 10 levels per chapter, each chapter a lighthearted riff on a different AI system (a Claude-inspired land, a Grok-inspired land, an OpenAI-inspired land, and more).
- **Bosses** — A mini-boss every 5 waves, a big boss every 10.
- **Speed controls** — 1x / 2x / 5x, plus a "send the next wave early" button that earns you bonus points.
- **Enemy abilities** — As you progress, enemies gain their own tricks: rush bursts, shields, healers, tower-jammers, splitters, and adaptive bosses.


## The defenders


Unlock new avatar defenders across the first 10 levels. Each has its own range, role, and look — and they change visually as you upgrade them (long-press a tower for upgrade/sell options).


- **Archer** — fast, low-damage arrows
- **Crossbow** — slower, harder-hitting bolts
- **Wizard** — starts plain, then branches into an elemental path:
  - ❄️ Ice path → **Frost Wizard** (slows)
  - 🔥 Fire path → **Fire Mage** (burn damage)
  - ⚡ Lightning path → **Lightning Wizard** (electrify / chain hits)
  - Each path earns a pointy wizard hat in its color at legendary rank
- **Goop** — slows and sticks enemies
- **Cannon** — big area-of-effect damage
- **Miasma** — area debuffs (poison, slow, burn)
- Plus more unlockables and a support defender that buffs nearby towers


## Run it yourself


This repo is a single self-contained HTML file — no build step, no dependencies:


```bash
# Just open it
open avatar-tower-defense.html
# or serve it
python3 -m http.server
```
